### 4. Задание 1. Сравнение сред выполнения (Node.js и браузер)

Скрипт `practice-01/js/hello.js` запущен в двух средах: через консольную команду `node practice-01/js/hello.js` и через подключение в HTML-странице `practice-01/index.html` с просмотром вкладки Console в инструментах разработчика.

**Результат запуска:**
- В консоли терминала (Node.js):
  ```text
  Студент: Панов Алексей Алексеевич
  Группа: ЭФБо-13-25
  Практическая работа: 1
  JavaScript успешно запущен
  Тип document: undefined
  ```
- В консоли браузера (DevTools Console):
  ```text
  Студент: Панов Алексей Алексеевич
  Группа: ЭФБо-13-25
  Практическая работа: 1
  JavaScript успешно запущен
  Тип document: object
  ```

**Объяснение различия:**
Node.js предназначен для выполнения JavaScript вне браузера (на сервере или локальной машине). В этой среде нет графического окна и HTML-разметки, поэтому глобальный объект `document` отсутствует (`typeof document` возвращает `"undefined"`). В браузере JavaScript работает с деревом документа (DOM), и объект `document` предоставляет API для управления содержимым страницы, имея тип `"object"`.

### 5. Задание 2. Исследование типов и преобразований

| № | Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |

| 4 | `"12" > "3"` | `false`, boolean | `false` | `boolean` | Строки сравниваются лексикографически посимвольно по кодам символов. Символ `'1'` (код 49) меньше символа `'3'` (код 51), поэтому результат `false`. |

| 9 | `typeof null` | `"object"`, string | `"object"` | `string` | Историческая особенность реализации JavaScript: значение `null` имело нулевой тег типа объекта. Результат оператора `typeof` всегда является строкой. |

### 6. Задание 3. Сводка выполнения задач (`progress.js`)

**Реализованная логика:**
1. Проверка типов: аргументы должны быть числами (`typeof === "number"`) и целыми значениями (`Number.isInteger()`).
2. Проверка диапазонов: `0 <= totalTasks <= 1000` и `0 <= completedTasks <= totalTasks`.
3. При ошибке валидации выводится диагностическое сообщение вида `Ошибка: ...`, дальнейший расчёт прерывается.
4. При `totalTasks === 0 && completedTasks === 0` выводится `Задач пока нет`.
5. При корректных данных вычисляются `remaining = total - completed`, `progress = (completed / total * 100).toFixed(1)` и статус (`Не начато`, `В работе`, `Завершено`).

### 7. Задание 4. План выполнения по дням (`plan.js`)

**Реализованная логика:**
1. Проверка `totalTasks` и `completedTasks` по правилам Задания 3.
2. Проверка `dailyLimit`: целое число от 1 до 1000.
3. Если оставшихся задач нет, цикл не запускается, выводится сообщение и `Потребуется дней: 0`.
4. В цикле `while (remaining > 0)` вычисляется объем работы на день `Math.min(limit, remaining)` и уменьшается остаток.

**Таблица проверок:**

| Входные данные (`total`, `completed`, `limit`) | Ожидаемый результат | Фактический результат | Итог |

### 8. Задание 5. Отладка (`debug.js`)

**Исходный вывод программы с ошибками:**
```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

**Анализ причин и исправления:**

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Сложение строк вместо чисел | `completedTotal = 32` | `completedText` и `additionalText` хранили строки `"3"` и `"2"`. Оператор `+` выполнил конкатенацию `"32"`. При вычитании `"8" - "32"` получилось `-24`. | Добавлено явное приведение: `Number(completedText) + Number(additionalText)` и `Number(plannedText) - completedTotal`. | `Выполнено: 5`, `Осталось: 3` |
| Неверная граница цикла | `Контрольная сумма: 6` | Условие `taskNumber < 4` исключило значение `4`, просуммировав только `1 + 2 + 3 = 6`. | Условие цикла заменено на нестрогое: `taskNumber <= 4`. | `Контрольная сумма: 10` |

**Итоговый вывод после исправления:**
```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

### 9. Вывод
В ходе работы освоен базовый цикл разработки на JavaScript: написание модульного кода, запуск в среде Node.js и браузере, типизация данных и отладка в инструментах разработчика.

Наиболее показательной ошибкой оказалась неявная конкатенация строк оператором `+`: в отличие от строго типизированных языков, JavaScript не выбрасывает ошибку времени выполнения, а формирует строку `"32"`, которая затем приводит к искажению дальнейших расчетов (`-24`). Это подтверждает необходимость строгой валидации типов и явного преобразования входных данных через `Number()` с проверкой `Number.isInteger()`.
