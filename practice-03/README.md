## Организация кода

- `src/data.js` — источник исходных данных (`demoTasks` и `variantTasks`). Модуль автономен и не работает с DOM.
- `src/task-service.js` — прикладная логика из ПР2. Содержит чистые функции создания, поиска, изменения статуса, удаления и подсчета сводки.
- `src/task-selectors.js` — вычисляет выборку задач для отображения через `getVisibleTasks(tasks, filter)`.
- `src/task-view.js` — модуль отображения: создает `li.task-card` через `createElement` и `textContent`, обновляет сводку по пяти параметрам (`renderSummary`) и управляет блоком пустого списка (`renderEmptyState`).
- `src/main.js` — точка входа: хранит переменные текущего состояния (`currentTasks`, `currentFilter`), подписывает контейнеры на события и координирует перерисовку интерфейса (`renderApp`).

Полный список и фильтр хранятся в модуле `main.js`. События обрабатываются на уровне стабильных родительских контейнеров `ul#task-list` и `div#task-filters`. Сводка рассчитывается в `task-service.js` функцией `getTaskStats(currentTasks)` и отображается модулем `task-view.js`.

## Отладка и клавиатура

При отладке в `handleTaskListClick` точка останова установлена на строке извлечения `id`:
```javascript
const id = Number(card.dataset.taskId);
```
Значения в отладчике при клике на задачу 4:
- `event.target`: элемент `<span class="action-label">Выполнена</span>`
- `event.currentTarget`: элемент `<ul id="task-list">`
- `card.dataset.taskId`: строка `"4"`
- `id`: число `4` (числовой тип)
- `action`: `"toggle"`
- `result`: `{ ok: true, tasks: [...] }`

Клавиатурная навигация проверена клавишами Tab, Enter и Space: фокус последовательно переходит между фильтрами и кнопками карточек. После нажатия Enter на кнопке статуса фокус сохраняется на обновленной кнопке карточки с помощью вызова `restoreTaskFocus(id, action)`. При удалении задачи фокус корректно перемещается на активную кнопку фильтра.

При ручной подмене `data-task-id` на `777` выводится сообщение `Ошибка: задача с id = 777 не найдена.` При подмене на `4abc` проверка `Number.isSafeInteger(id)` фиксирует `NaN` и выводит `Ошибка: некорректный идентификатор задачи.`

## Вывод

В ходе практической работы разработана браузерная часть приложения управления задачами. Изучены принципы взаимодействия с DOM, генерация элементов через методы API (`createElement`, `replaceChildren`) и безопасный вывод текстового контента (`textContent`).

Установлено различие между изменением DOM и изменением данных приложения: прямое удаление узлов дерева разметки не сохраняет состояние, тогда как корректная архитектура опирается на однонаправленный поток: событие пользователя вызывает функцию сервисного слоя, валидирует результат, обновляет массив в памяти и инициирует детерминированную перерисовку интерфейса.
